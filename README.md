## Sliding Puzzle Solver
![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)
![BFS](https://img.shields.io/badge/Breadth--First%20Search-BFS-blue?style=for-the-badge)
![LinkedList](https://img.shields.io/badge/LinkedList-Queue-orange?style=for-the-badge)

A grid-based puzzle-solving application designed to find the shortest path from a starting point to a finish point. The project implements the Breadth-First Search (BFS) algorithm along with a LinkedList-based Queue data structure to efficiently traverse the grid and determine the shortest path.
